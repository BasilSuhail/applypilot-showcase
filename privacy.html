Privacy Policy

Last updated: 21 October 2026

ApplyPilot UK ("the app") is a personal tool, used only by its developer, Basil Suhail, to help with his own job applications. It is not offered to the public. Nobody else signs in to it.

Google user data the app accesses

With the owner's permission, the app uses the Gmail API to read the owner's own email. It uses this to:

  • find verification codes and password-reset links sent by job sites during an application;
  • check whether an account already exists on a job site;
  • notice replies from employers (for example interview invitations) and send the owner a short alert.

The app does not send, delete, label or change any email.

How data is used and stored

  • Everything runs locally on the owner's own computer. Email content is processed in memory and is not stored. Only a message ID, the sender, the subject and a category are kept in a local database, to avoid duplicate alerts.
  • A short alert (sender, subject, job title, category) is posted to the owner's own private Discord channel.
  • The owner's job-search data (CV, job listings, applications) lives on the owner's computer, plus an encrypted backup on a server the owner controls.

Sharing

No Google user data is sold, shared with third parties, used for advertising, or used to train AI models. Google user data is never transferred to anyone other than the owner.

Google API Services User Data Policy

ApplyPilot UK's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Local data can be deleted by removing the app's data folder.

Contact

Questions: open an issue on GitHub.
