How a job flows

Search (Indeed, 5 regions) → dedupe → AI score 1-10 → tailored CV + cover letter → Claude agent applies in Chrome → ✅ applied / 🔔 CAPTCHA hand-off / 🗂️ saved for me → 📬 Discord ping on replies

What it does

🤖 Applies for me

A Claude agent drives a real Chrome window: Workday, SuccessFactors, iCIMS, Greenhouse, Lever and more. It handles logins, screening questions and uploads.

🧠 Judges fit honestly

Scores each ad against my CV with hard blockers (clearance, licence, language, nationals-only), so only real fits get an application.

📄 Writes every CV fresh

A one-page CV and cover letter per job, from my real experience and checked by an AI judge.

🙋 Asks only when needed

One beep for a CAPTCHA. Anything it can't finish is saved with everything I need to do it by hand.

📬 Watches for replies

Reads my Gmail (read-only) every 10 minutes and pings Discord for interviews and assessments. Never rejections.

🔒 Private by design

Runs on my own Mac. Personal data never leaves it, apart from an encrypted backup on my own server.
