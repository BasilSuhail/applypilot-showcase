# 🗺️ Roadmap

## ✅ Done

**Pipeline**
- [x] UK-first fork of ApplyPilot: search, score, tailor, apply, report.
- [x] One-page tailored CV and cover letter for every good fit.

**Applying and logins**
- [x] Login handling: Google sign-in, account check via Gmail, create account, password reset via Gmail.
- [x] Screening answers from a private profile (right to work, salary by region, referees, equality monitoring, essays).

**Human in the loop**
- [x] CAPTCHA hand-off: one beep, 30 seconds, then kept for the next session and done first.
- [x] Manual pile with a ready-to-send folder per job, plus assist mode where the agent works them with me.

**Search, queue and data**
- [x] Duplicate detection: same job under a different link, or the same company and title.
- [x] Multi-region search with priority order (UK → Middle East → Europe → Canada → Pakistan).
- [x] Fresh-start queue clearing, plus clearing of the manual pile.

**Reporting and ops**
- [x] Live "this round" lists after every step, and Excel reports.
- [x] Discord alerts for employer replies (interviews, assessments, real messages; never rejections).
- [x] Encrypted backup to my own server with a one-command restore.

## 🔜 Next

1. **Company job boards with no logins.** Pull jobs straight from Greenhouse, Lever and Ashby via their public job feeds. These forms rarely need an account or show a CAPTCHA, so more applications finish with no help at all.
2. **Reply tracking in the reports.** A Response column (interview, assessment, rejection, no reply) and reply rates by role type, region and site. This shows what actually works.
3. **Skip dead ads.** Check that a job is still open, and flag reposts, before spending an application on it.

## 💡 Later

- Discord pings for bot events: "CAPTCHA needed", "round finished".
- Interview prep notes generated per job from the ad and my CV.
- Follow-up reminders for applications with no reply after two weeks.
